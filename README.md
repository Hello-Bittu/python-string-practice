## Practice Sections

### 1. Basic String Operations
Practice with basic string operations such as accessing characters, finding string length, and concatenating strings.

Practice with indexing, slicing, extracting parts of strings, and reversing strings.

### 3. String Methods and Functions
Practice with common string methods and functions such as removing spaces, changing case, counting characters, and checking alphanumeric strings.

### 4. String Formatting and f-Strings
Practice with `format()` and f-strings to create formatted output.

### 5. String Manipulation
Practice with replacing text, finding indexes, and changing the case of strings.

### 6. Bonus Questions
Additional practice problems including counting vowels and checking whether a string is a palindrome.
